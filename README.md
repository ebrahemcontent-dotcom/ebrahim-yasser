# سيرفر تحميل الفيديو + التحليل (Viral Analyzer Backend)

السيرفر ده بياخد لينك (تيك توك / انستجرام / فيسبوك / يوتيوب)، بينزل الفيديو بأداة `yt-dlp`،
بيستخرج منه فريمات بـ `ffmpeg`، وبيرجعهم JSON. وكمان بيتصل بـ Claude API بمفتاحك الخاص
عشان يحلل الفريمات والسكريبت ويرجع تقرير كامل — الأداة (صفحة الويب) بتاخد النتيجة دي وتعرضها.

**مهم جدًا:** التحليل بالذكاء الاصطناعي **لازم يعدي من هنا** (السيرفر) مش من المتصفح مباشرة.
لو فتحت صفحة الأداة لوحدها من غير السيرفر ده متوصّل ومفعّل، زرار "حلل الفيديو" مش هيشتغل خالص —
مفيش أي طريقة تانية يشتغل بيها برّا شات Claude.

---

## ١. مفتاح Anthropic API (خطوة إجبارية)

1. روح [console.anthropic.com](https://console.anthropic.com) واعمل حساب
2. من **API Keys**، اعمل مفتاح جديد وانسخه (بيبان مرة واحدة بس، احفظه في مكان آمن)
3. لازم تحط فلوس في الحساب (Billing) — الاستخدام بيتحاسب على حسب عدد التوكنز، مش اشتراك ثابت.
   التكلفة لكل تحليل صغيرة جدًا (كسور من السنت للصورة الواحدة)، لكن لازم رصيد موجود عشان المفتاح يشتغل.

## ٢. أسرع طريقة تنشره: Render.com (فيه خطة مجانية)

1. اعمل حساب على [render.com](https://render.com)
2. ارفع الفولدر ده (viral-backend) على GitHub repo جديد (خاص أو عام)
3. من لوحة Render: **New > Web Service**، اختار الـ repo
4. Render هيلاقي الـ `Dockerfile` أوتوماتيك ويستخدمه — سيبه كده
5. قبل ما تدوس Deploy، روح لتبويب **Environment** وضيف:
   - `ANTHROPIC_API_KEY` = المفتاح اللي نسخته فوق
6. دلوقتي دوس **Deploy**
7. استنى 3-5 دقايق لحد ما يخلص البناء
8. هتاخد رابط زي: `https://your-app-name.onrender.com`
9. افتح صفحة أداة التحليل، حط الرابط ده في خانة "رابط السيرفر الخلفي"، واحفظه

> ملحوظة: الخطة المجانية في Render بتنام بعد فترة عدم استخدام، فأول طلب بعد فترة راحة
> ممكن ياخد ٣٠-٦٠ ثانية لحد ما السيرفر يصحى. ده طبيعي.

### بديل: Railway.app
نفس الخطوات تقريبًا — ارفع الريبو، Railway بيكتشف الـ Dockerfile، وبيديك رابط مباشرة.

### بديل: على جهازك أو VPS بتاعك (تجربة محلية)
```bash
cd viral-backend
docker build -t viral-backend .
docker run -p 3000:3000 viral-backend
```
السيرفر هيشتغل على `http://localhost:3000`

## حدود مهمة لازم تعرفها

- **الفيديوهات الخاصة (Private)** على انستجرام أو فيسبوك مش هتنزل، لأن `yt-dlp` محتاج تسجيل
  دخول لها. الفيديوهات العامة (Public) بس هي اللي هتشتغل من غير إعدادات إضافية.
- **مدة الفيديو محدودة بـ ٤ دقايق** في الكود الحالي (`MAX_DURATION_SECONDS`) عشان السرعة
  والتكلفة — تقدر تغيرها في `server.js`.
- **انستجرام وفيسبوك بيغيروا سياساتهم بشكل متكرر**، فـ `yt-dlp` ممكن يحتاج تحديث كل فترة.
  حدّثه بتشغيل نفس أمر التحميل اللي في الـ Dockerfile تاني، أو بعمل rebuild للـ image.
- الخطة المجانية على Render فيها حد لعدد الدقايق شهريًا — لو الاستخدام كبر هتحتاج خطة مدفوعة
  رخيصة نسبيًا (من حوالي 7$/شهر).

## اختبار سريع بعد النشر

```bash
curl -X POST https://your-app-name.onrender.com/api/extract \
  -H "Content-Type: application/json" \
  -d '{"url": "رابط فيديو عام من تيك توك هنا"}'
```

لو رجعلك JSON فيه `frames`، يبقى شغال تمام.

بعد كده جرب endpoint التحليل نفسه (لو عندك سكريبت جاهز):

```bash
curl -X POST https://your-app-name.onrender.com/api/analyze \
  -H "Content-Type: application/json" \
  -d '{"frames": [], "script": "النص اللي بيتقال في الفيديو هنا"}'
```

لو رجعلك JSON فيه `viral_score`، يبقى المفتاح والتحليل شغالين صح.
